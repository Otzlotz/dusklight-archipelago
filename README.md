# Dusklight Archipelago

A unofficial mod for [Dusklight](https://github.com/TwilitRealm/dusklight).

## Building

```sh
git clone https://github.com/otzlotz/dusklight-archipelago/
cmake -B build
cmake --build build --parallel 
```

The compiled mod is `build/mods/archipelago.dusk`. Copy it into the game's mods folder to try it:

- Windows: `%APPDATA%\TwilitRealm\Dusklight\mods`
- Linux: `~/.local/share/TwilitRealm/Dusklight/mods`
- macOS: `~/Library/Application Support/TwilitRealm/Dusklight/mods`
